# Pi-hole-unified-dashboard

This project is a dashboard that aggregates the metrics across multiple pi-hole instances on a network into a single dashbaord view.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
